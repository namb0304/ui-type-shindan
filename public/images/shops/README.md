# お店の写真

結果ページのファーストビューに敷く写真を、タイプコードの名前で置く。

- ファイル名：`DFCG.webp` 〜 `ARPM.webp`（16タイプ）
- 推奨サイズ：1080 × 1440px（3:4の縦長）
- 容量の目安：1枚150KBまで
- 読み込むのは、結果に出たタイプの1枚だけ

PNGからの変換：

```bash
brew install webp
cwebp -q 72 -resize 1080 0 DFCG.png -o DFCG.webp
```

150KBに収まらないときは品質を下げる（`-q 62`）か、横幅を900pxにする。
写真は65%以上の幕をかけて薄く表示するので、多少圧縮しても見た目に影響しない。

ファイルが無いタイプは、テーマ色のグラデーションだけで表示される。
